vWeb Privacy Policy

Data vWeb handles

vWeb organizes open tabs, tab groups, and bookmarks. It uses open tab titles, URLs, and group information to show and search your tabs. It stores the bookmarks, saved groups, workspaces, tags, notes, and settings you create or import. When you save a page with site access enabled, it may read the page title, description, or text you select to populate the bookmark.

Storage and sharing

vWeb searches and stores this data in your browser profile. The extension operates without a developer account service, cloud sync, analytics, advertising, or a remote icon lookup service. Opening a result navigates to that website. Choosing web search sends your query through your browser to its configured search provider. Following a link, including the source attribution link, opens the linked site.

Optional access to websites

The search overlay is off by default. In Settings, you can enable site access to use the overlay from websites and turn access off again. The extension uses an extension-owned frame for the overlay and reads page details on demand when you save a bookmark.

Retention and deletion

Saved data stays in your browser profile until you delete it. Items in Trash can be restored until you delete them permanently. You can create and restore a local JSON backup from Settings. Backups may include private URLs and notes and remain wherever you save them. Deleting data from the extension does not delete exported files.

Chrome Web Store Limited Use

vWeb’s use of information obtained from Chrome APIs follows the Chrome Web Store User Data Policy, including its Limited Use requirements.

Contact

For privacy questions, use the developer contact on the vWeb listing in the Chrome Web Store.

מדיניות הפרטיות של vWeb

מידע שהתוסף מעבד

התוסף מארגן לשוניות פתוחות, קבוצות וסימניות. הוא משתמש בכותרות, בכתובות ובפרטי הקיבוץ כדי להציג לשוניות ולחפש בהן. הוא שומר סימניות, קבוצות שמורות, סביבות עבודה, תגיות, הערות והעדפות שיוצרים או מייבאים. כאשר שומרים עמוד עם גישה לאתרים מופעלת, התוסף עשוי לקרוא את כותרת העמוד, את התיאור שלו או את הטקסט שסומן כדי למלא את פרטי הסימנייה.

אחסון ושיתוף

החיפוש והאחסון מתבצעים בפרופיל הדפדפן. התוסף פועל ללא חשבון מול המפתח, סנכרון בענן, מדידה, פרסומות או שירות אייקונים חיצוני. פתיחת תוצאה מעבירה לאתר שנבחר. בחירה בחיפוש באינטרנט שולחת את השאילתה דרך הדפדפן למנוע החיפוש שהוגדר בו. קישורים, כולל קישור הייחוס, פותחים את האתר שאליו הם מפנים.

גישה אופציונלית לאתרים

חלונית החיפוש כבויה כברירת מחדל. אפשר להפעיל גישה לאתרים מתוך ההגדרות כדי לפתוח את החלונית בזמן גלישה, ולבטל אותה באותו מקום. החלונית מוצגת במסגרת נפרדת של התוסף. פרטי עמוד נקראים לפי הצורך בזמן שמירת סימנייה.

שמירה ומחיקה

נתונים נשמרים בפרופיל עד שמוחקים אותם. אפשר לשחזר פריטים מהאשפה עד למחיקה לצמיתות. אפשר להוריד ולשחזר קובץ גיבוי מקומי מתוך ההגדרות. קובצי הגיבוי עשויים לכלול כתובות והערות פרטיות ונשמרים ביעד שנבחר. קבצים שיוצאו מנוהלים בנפרד מהנתונים שבתוסף.

שימוש מוגבל לפי מדיניות החנות

השימוש של vWeb במידע שמתקבל מממשקי הדפדפן כפוף למדיניות נתוני המשתמש של חנות התוספים של כרום, לרבות דרישות השימוש המוגבל.

יצירת קשר

בשאלות פרטיות ניתן לפנות לפרטי הקשר של המפתח שמופיעים ברישום של vWeb בחנות התוספים של כרום.
